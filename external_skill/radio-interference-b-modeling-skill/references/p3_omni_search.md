# 问题三：全向多源自动搜索定位与清除

## 分层架构
覆盖层：选择少量扫描点获取远距离信息。
定位层：为已发现频道维护扇区交集/候选区域，必要时主动补测。
调度层：联合考虑移动、换频、检测、定位、清除的时间成本在线重规划。

## 状态
当前位置、当前频道、虚拟时间、已扫描区域、频道状态、每个目标的观测集合/候选区域/置信度、已清除集合、剩余预算。

## Baseline
固定扫描点 + 顺序频道扫描 + 最近邻目标处理。

## 改进
- 覆盖点集合通过离散 set-cover / facility-location 搜索，而非直接假设点数。
- 频道策略根据未发现/已发现/已清除状态动态排序。
- 下一动作以信息增益/预计定位收缩量/预计耗时的比值评分。
- 路径可用最近邻作为在线 baseline，再尝试 2-opt、模拟退火或滚动时域。

## 验证
Monte Carlo 随机场景至少报告：清除率、总虚拟时间、移动距离、检测次数、换频次数、单源平均处理时间，以及失败场景。
