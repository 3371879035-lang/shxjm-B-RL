# 问题四：混合全向/定向干扰源

## 关键变化
定向源存在“看不见”的检测点。no-signal 是信息，但存在多重解释，必须保留为约束而非删除目标假设。

## 表示
对每个频道维护位置候选 G 与方向候选 φ。检测到信号：距离约束 + 方位扇区 + 定向覆盖内积约束；未检测到：在已确认距离可达的条件下，可对 φ 增加排除约束。

## 策略
1. 复用问题三全局扫描。
2. 根据跨检测点的 signal/no-signal 模式判断定向源嫌疑。
3. 对高价值目标选择方位多样的验证点；相反方向观测是重要几何构型。
4. 已足够接近时优先进入最终定位/清除，避免为估计 φ 过度耗时。
5. 比较 2 点相反方向、4 点正交环绕、信息增益自适应选点的时间与成功率。
