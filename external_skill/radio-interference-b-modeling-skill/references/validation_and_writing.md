# 验证、写作与审查

## 实验层级
A. 单元测试：角度、半平面、交点、凸包、直径、最小包围圆。
B. 子模型：第二检测点热图；定位误差随交会角变化。
C. 系统仿真：多源随机场景，baseline vs 改进策略。
D. 敏感性：测角误差、接收半径、源数量、定向源比例、时间成本。
E. 消融：关闭动态频道/信息增益/重规划，量化贡献。

## 论文结构
问题重述 → 假设与符号 → 问题一几何模型 → 问题二信息选点 → 问题三在线搜索 → 问题四定向扩展 → 实验验证 → 敏感性/鲁棒性 → 模型评价。

## 图表
交会扇区与定位多边形、直径/最小包围圆、FIM 或误差热图、扫描覆盖图、搜索轨迹、候选区域演化、时间组成、Monte Carlo 箱线图/ECDF、消融对比。
