# 问题一：交会定位区域、直径与圆覆盖

## 建模链
示向度 ±ε → 每个检测点形成角度扇区 → 用两个半平面表示扇区 → 连续裁剪初始可行域 → 得到凸多边形 → 求直径 → 求最小包围圆。

## 实现
1. 角度归一化并构造两条边界方向向量。
2. Sutherland–Hodgman 半平面裁剪；初始区域应来自正式题目的空间边界。
3. 清理重复/近共线顶点并检查凸性、方向顺序。
4. 用旋转卡壳求凸多边形直径 D，同时用全顶点对暴力法验证。
5. 计算最小包围圆半径 Rmin；判断 Rmin <= D/2 是否成立。

## 必做实验
随机生成一致观测、近似平行方向、跨 0° 角度、空交集、三角形/四边形退化案例；比较精确几何结果与数值容差敏感性。
