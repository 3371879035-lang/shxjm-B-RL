# 问题二：第二检测点选择

## 核心思想
把第二检测点选择建模为“定位信息收益 - 行动代价”的权衡。讲义给出的核心候选指标包括交会区域面积与 Fisher 信息矩阵；交会角接近 90°通常有利，但实际选点必须同时满足距离、有效接收范围、可达性和移动时间约束。

## 推荐目标
对候选 S2 计算：
- 几何交会区域面积/直径的期望或最坏值；
- det(FIM) 或 trace(inv(FIM))；
- 移动时间；
- 在未知源距离下的鲁棒性。
构造加权目标或 Pareto 前沿，而不是只追求 90°。

## 实验
对不同距离先验、测角误差、接收半径和移动成本做网格扫描，画候选区域热图；与“固定垂直选点”“最近可行点”比较。
