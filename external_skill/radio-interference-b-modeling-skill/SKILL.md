# Radio Interference B Modeling Skill

## 使用原则
本 Skill 将讲义转化为可执行建模流程，而非要求复制讲义文字。所有结论、参数、模拟器协议和实验数据必须以用户提供的正式赛题/附件/实际运行结果为准。禁止虚构测试结果。

## 总工作流
1. 读取正式赛题、附件和模拟器协议；生成 `problem_spec.md`。
2. 建立参数表、单位表、时间成本表、动作约束表。
3. 按问题路由到对应 reference。
4. 先实现可验证 baseline，再实现改进模型。
5. 对关键几何/优化结论做数值交叉验证。
6. 输出代码、实验、图表、论文段落时保持同一套符号和参数。
7. 最后执行论文与实验质量 Gate。

## 问题路由
- 问题一 → `references/p1_geometry.md`
- 问题二 → `references/p2_sensor_selection.md`
- 问题三 → `references/p3_omni_search.md`
- 问题四 → `references/p4_directional_search.md`
- 写作、实验与审查 → `references/validation_and_writing.md`

## 强制质量 Gate
- 角度统一为弧度计算，处理 0°/360° 环绕。
- 扇区/半平面方向必须用测试点验证内外侧符号。
- 空交集、共线、近似平行、重复顶点必须显式处理。
- 旋转卡壳结果用 O(m²) 顶点对暴力法交叉验证。
- 最小包围圆与直径圆覆盖结论用数值样例验证。
- Fisher 信息指标不得脱离距离、可达性、接收半径与移动成本单独优化。
- “未检测到信号”不得直接等价于“不存在干扰源”，尤其是定向源。
- 所有时间预算必须包含移动、检测、换频、光学定位和清除。
- 所有模拟结果必须来自真实代码执行；未运行时使用 TODO，不得编造均值、成功率或排名。
- 讲义中的近似公式、扫描点覆盖主张和阈值均视为候选方案，使用前通过正式题面和仿真重新验证。
