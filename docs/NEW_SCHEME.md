## 1. 第4问25点保证覆盖

构造：

```text
S25 = {O} ∪ {I_k, k=0..11} ∪ {E_k, k=0..11}
O = (0,0)
I_k = 970 * (cos(15°+30°k), sin(15°+30°k))
E_k = 1880 * (cos(30°k), sin(30°k))
```

- 外正十二边形内切圆半径：1880*cos15° = 1815.94m > 1800m，覆盖整个目标圆。
- 原点、内环、外环把覆盖区域剖分为36个三角形，最大边长975.897m < 1000m。
- 任意目标位于某个三角形内，到三顶点距离均小于1000m；任意180度发射半平面至少包含一个顶点，因此至少一个测点可接收。
- 一条明确开路路线 O→I0→...→I11→E0→...→E11 长约18173.85m。
- 原31点网格任意完整访问路线至少30*950=28500m，因此完整固定覆盖巡航长度至少降低36.2%。

## 2. 双侧区间定位

首次有效示向后，把局部坐标x轴取为示向方向，真实源满足：

```text
0 <= x <= 1500,  |y| <= x * tan(1.01°)
```

维护x区间[l,u]。当宽度大于24m时，取中点a、侧偏b=a*tan(1.01°)+5，测试(a,b)和(a,-b)：

- 两侧都no_signal => x < a。证明利用：若x>=a，则首次测点与源连线与x=a的交点位于两探测点之间，且两点都比首次测点离源更近，不可能同时不可见。
- 任一侧direction => 用示向和误差界更新区间。
- near => 直接clear。

每轮区间至少折半，6轮后宽度<=1500/64=23.4375m。末端两点 ((l+u)/2, ±u*tan(1.01°)/2) 覆盖剩余矩形，最大距离约17.856m < 20m。因此单源最多12次追加测向、2次末端光学尝试。

## 5. P0严格外包修复与G25OR

原`initial_track_polygon`使用半径1500m的边界射线和远边弦，中央方向最大只到1500*cos(1.01°)=1499.767m，存在约0.233m的极薄区域不在保守三角形内。现改为：

```text
L = 1500 / cos(1.01°)
P = [p, p + L*u(theta-1.01°), p + L*u(theta+1.01°)]
```

这样三角形包含半径1500m扇形的全部可能位置。随机验证：167358个位于目标圆内的有效扇形点，0个漏出保守三角形。
