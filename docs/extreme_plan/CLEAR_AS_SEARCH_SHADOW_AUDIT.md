# Clear-as-Search Shadow Audit：清除/定位停点能否替代搜索

## 1. 实验问题

不真正改算法，只回放现有 G25OR 轨迹，回答一个具体问题：

> 如果机器狗在原本为了定位、清除而停下来的位置顺手测量尚未发现的频道，未来到底能删掉多少 S3/S25 搜索任务？

实验复用 Q3/Q4 各 50 个严格配对场景，不新增场景、不上官方模拟器、不训练模型。

## 2. 审计口径

1. 原样跑 G25OR-S25，记录每局所有 natural stop：S3/S25 覆盖测点、双边定位点、refinement 测点、clear 点。
2. 对每个非覆盖自然停点，影子测量当时所有尚未发现的频道。
3. 用 Q3 严格 1000 m 圆盘证书、Q4 180 度定向源凸包证书更新搜索证书，统计未来可删任务。
4. 本报告的 valid 指标是保守合法口径：只删除由影子测量直接发现或可严格证明全局不存在的频道任务。gross 是乐观上界口径：忽略证书和测量成本，直接删除首个非覆盖停点之后的所有覆盖任务，用来判断理论天花板。
5. 原轨迹不受影响，所有节省均为离线重放估计。

## 4. 为什么失败

1. **自然停点位置不对，不是数量不够。** 首个非覆盖停点处平均还有 5.92/7.84 个真实源未发现，但在这些位置顺手测量真正发现的新源是 0/10 次。原因是双边定位点和 clear 点都围绕已发现源/已清除源，离剩余未知源通常既不在 1000 m 内，也不在定向源可见半平面内。
2. **影子 no_signal 很难形成全局不存在证书。** 非覆盖停点集中在局部轨迹附近，其 no_signal 只能排除局部单元；50 局中 Q3 仅 1 局有 4 个空频道在乐观免费信息下可全局判不存在，Q4 为 0。由于证明出现得太晚，未来覆盖任务已基本执行完，无法转成整航点删除。
3. **整航点删除数为 0。** 合法口径下，全部 100 局没有任何一个 S3/S25 物理航点能被删除，专用搜索距离节省为 0 m。乐观上界虽然能删 4.46/17.88 个航点，但它要求首停点之后所有搜索任务都凭空消失，这需要证书全部免费且成立，实际不可能。
4. **顺手测量的固定成本很高。** 每个未知频道每次测量约 5 s（换频另加 1 s）；在 35.4/53.9 个非覆盖停点上测所有未知频道，平均新增 308.76/1056.32 s/局，远超任何可回收的搜索时间。

## 5. 结论与建议

- **Q3 明确不建议实现 B3。** 即使采用免费证书、免费测量的 gross 上界，平均也只有 25.02 s/源，低于 30-40 s/源 Gate；合法口径为负。
- **Q4 名义上 gross 上界 109.11 s/源，超过 70-100 s/源 Gate，但该上界不可达。** 合法口径下删除任务 0.20 个/局、整航点 0 个、距离节省 0 m，净节省 -81.54 s/源；甚至 oracle 只测信号频道也只有 -0.89 s/源。
- 因此，**在最早期望的机制上，G25OR 的 clear/定位停点不能替代搜索任务**。搜索路线与清除路线要合并，必须重新设计搜索感知的路线/停点，而不是在现有 clear/定位停点顺手插测量。
- 本实验是对下一步路线合并假设的负结果，不建议据此实现 B3；后续应转向可证明的在线搜索-清除联合路线本身。
