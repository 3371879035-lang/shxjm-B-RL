## 03  Q1：先把解题对象与几何证书锁定

Q1要求计算“交会定位多边形”的直径，并回答同直径圆能否覆盖。最小包围圆不能代替第一项答案。[O1]

```text
uᵢ = (cos θᵢ, sin θᵢ)，vᵢ = (−sin θᵢ, cos θᵢ)
```

```text
uᵢ·(z−sᵢ) ≥ 0；|vᵢ·(z−sᵢ)| ≤ tan ε · uᵢ·(z−sᵢ)
```

数学题面取ε=1°。机器接口返回两位小数时，工程实现可取1.01°保守处理；二者在文中分开说明。半平面法避免斜率无穷和359°/0°绕回问题。

### 基准实现与退化状态

先区分空集、无界、单点、线段和有界多边形。对有界凸多边形，枚举全部顶点对得到直径，作为可信对照。只有经过独立对照的旋转卡壳才用于加速；点数很少时没有必要冒险。

不能用任意大矩形将无界集合截断后，报告“有限直径”；也不能把圆域/接收圆的多边形近似混称为Q1原始定位多边形。后续Q3/Q4加入圆约束得到的是另一个可行集合，近似须明确内外包方向。

### 一个由合法测向楔形实际生成的反例

| 检测点 | 示向度 |
| --- | --- |
| (−600, 0) | 1° |
| (320, −300√3) | 121° |
| (310, 310√3) | 241° |

三个±1°楔形的交为顶点(0,0)、(20,0)、(10,10√3)的等边三角形。直径20米，最小包围圆半径20/√3≈11.547米，大于10米。检测点、目标三角形与距离尺度都与题设相容。已用独立半平面枚举核对。

### 验收条件

MEC既要验证包含所有顶点，也要验证最小性：枚举1/2/3支撑点产生的圆，与主实现比较。CGAL文档给出平面MEC至多三个支撑点的性质，可作实现参照。[R7] 最终必须满足“真实位置仍在外包集合中→该集合能被20米圆包含→才能宣布可靠一次清除”。

## 04  Q2：保证接收不等于唯一最优候选区

首次有效示向后，令F为与首测角带、目标圆域和1500米距离上界一致的位置集合。需要给出候选区域及选点策略，不只是列出一个坐标。[O1]

### 保守候选区仍然成立

```text
Q₀ = ⋂g∈F B(g, 1000)
```

只要q∈Q₀，无论真实位置位于F的哪里，也无论接收半径具体是多少，都可以接收。这是充分条件，不应写成“全部合法第二测点”的精确集合。

### 利用首测已经收到信号，候选区域可以更宽

对给定候选源位置g，首测成功意味着实际接收半径还必须满足R≥||g−s₁||，而不仅是R≥1000。于是全向源条件下，可以使用更宽的条件保证区域：

```text
Q₁ = ⋂g∈F B(g, max{1000, ||g−s₁||})；Q₀ ⊆ Q₁
```

例如原检测点本来就已证实能接收，却可能不属于Q₀。它不是有用的新测点，但说明Q₀并非完整可见区域。计算Q₁时必须核对连续集合上的约束，不能未经证明只检查几颗采样粒子。

### 已有两个候选点可保留作基准

```text
q± = s₁ + 750u ± 300v
```

对0≤距离≤1500、角偏差≤1.01°的整个连续扇区，每一个候选点的最坏目标距离均约817.749米，小于1000米。验证应分别求每个点的最坏距离；“对每个目标选两点中更近者”只证明至少有一个可用，不证明任意选都可用。

### 选点优化的目标

用新增移动、测量、切频与后续清除完成成本共同评价，而不是只追求90°交会或面积下降。建议先给出“移动成本—最坏定位半径”的Pareto曲线，再将其中候选嵌入多源任务。预计平均成本所用的先验是自设模型，不能声称官方服从该分布。[R1]

## 05  极限参照：可计算的Oracle上下界

“开天眼133/400秒”在未说明场景和算法时不能当理论极限。对同一组真实位置与频道，完全知情后Q3/Q4的光学清除优化完全相同：发射方向不影响20米内清除。[O3]

### 为什么中心TSP不是正确下界

只有一个源位于(100,0)：走到真实中心需20秒、清除5秒，共25秒；走到(80,0)就能清除，共21秒。故中心访问路线是知情问题的一条可行上界，不是下界。问题实际属于“访问目标邻域”的开放CETSP。[R5]

### 用中心TSP包夹真正的20米邻域最优路线

设N个源，L꜀为从原点出发、不要求返回的最短中心TSP长度；Ldisk为访问全部20米圆邻域的最短路线。将每个实际访问点移至目标中心，第一段最多增加20米，其后每段最多增加40米。因此：

```text
max{0, L꜀ − (2N−1)×20} ≤ Ldisk ≤ L꜀
```

```text
5N + max{0,L꜀−(2N−1)×20}/5 ≤ Toracle ≤ 5N + L꜀/5
```

这个上下界区间的每源宽度最多为8−4/N秒，N≤16时不超过7.75秒。进一步把边权改为两个圆邻域之间的最短距离，再求开放路径DP，可以加强下界；它允许各边独立取端点，因而仍是松弛下界。

### 实现和正确用法

配套oracle_bounds.py提供Held–Karp：时间O(N²2ᴺ)、空间O(N2ᴺ)。已与N=1…8的排列穷举比较通过。组合搜索精确，浮点长度有数值余量；不能把它称为符号精确数值证明。N=16的实际速度应在队友电脑上基准测试，不能承诺每次在线重算只需几毫秒。

只对自建的同一场景比较策略与oracle。报告[T−UBoracle, T−LBoracle]作为最优差距范围，不拿不同分布的oracle均值与官方成绩做“严格差距”。离线评估器、在线规划器和正式runner必须隔离真值。

## 06  当前实验分支的两个具体审计发现

### A. Q3动态无源证书的边界包围不完整

当前_run_full中的_q3_absence_grid仅保留圆内的200米网格中心，再用每个中心半径100√2≈141.421米包围格子。这样没有覆盖整个目标圆的边缘细片。[C2]

```text
g=(1780,260)，||g||≈1798.889<1800
```

```text
g到最近保留中心≈189.737 > 141.421
```

这是该连续覆盖证明的缺口，不是声称已经观察到某一局官方漏源。修法是保留所有与圆域相交的单元，使用圆—矩形最近距离测试剔除完全在外的格子，再做角点/区间覆盖核验。这个问题位于实验full路径，不等于G25OR固定覆盖也失效。

### B. 交会角奖励的顶点选错了

geom_angle_bonus计算的是候选测点p处的夹角：向量first−p与estimated_source−p，然后给大角度更高奖励。它不是在候选源处比较两条观测方向。[C2]

```text
first=(0,0)，estimated_source=(1000,0)，p=(500,0)
```

旧评分夹角为180°，得到很高奖励；两次目标方位实际共线，交会横向几何的交叉正弦为0。正确因子可用|cross(first−g,p−g)|/(||first−g||·||p−g||)。0°和180°都不应被视为最佳交会。靠近源仍可能改善误差宽度，因此不等于总信息为0。

### 为什么这改变了对负结果的解释

之前full与G25OR差不多，只能说明当前实现与测试分布下没有证明额外收益；不能推出所有滚动规划都无效，也不能由p>0.17推出性能等价或已接近最优。应先核对新决策是否真正触发、比较的角度与证书是否正确，再讨论架构收益。

配套check_regressions.py可重现这两个见证，同时核对Q1楔形反例与Q2最坏距离。它不包含一个凭空宣称已修好的完整正式程序。

## 08  S21的独立证明与接入约束

### 逐单元的充分条件

用四叉树覆盖[-2048,2048]²。只有一个单元与半径1800米圆完全不相交时才删去。对每个保留的闭单元B，证书给出若干S21支撑点集合Sᴮ，并验证：

```text
B的四个角点严格位于conv(Sᴮ)内部
```

```text
每个支撑点到B的每个角点距离 < 999米
```

由凸性，整个B都在支撑点凸包内，且任意源g∈B到每个支撑点都小于999米。g在凸包严格内部，因此任何经过g的180°闭半平面都包含至少一个非重合支撑点。此点距离小于最小接收半径1000米，必能接收该定向源；全向源自然也能。

### 为什么独立校验器有意义

所有站点坐标为整数，单元边界是二进制有理数，通过统一缩放转为整数。独立检查器不导入证书生成器的凸包算法，而是逐边检查支撑多边形凸性、四角严格内含及距离条件，并从根节点递归检查完整分区。只给出一堆“通过的格子”但漏掉空洞，不能过检。

### 接入时不能只改points数组

策略的实际点集、RemoteBelief.coverage_points、n_coverage、频道scan_points编号与完成证书必须同步。不得让策略扫描S21而证明器仍按S25编号宣布完成。对方向、圆边界及站点恰好重合场景继续做完整交互回归。

保留S25版本独立运行，比较只换覆盖集的消融。S21不需要等待新在线规划器完成就能单独做本地及官方演练，但上线前必须确认通信端与数学证明使用同一组坐标。

### 论文表述

推荐称为“21点构造及整数几何辅助覆盖证书”。保留简单S25解析构造作为基准/解释；S21的创新点是经核验的构造，不是未证明的最少站点定理。证明包可放支撑材料。

## 09  主攻算法：统一停车决策，而不只重排站点

建议新策略称为“证书驱动主动搜索与情景滚动规划”。正确性层维护可能状态，快速层决定下一停车点及测量/清除动作。它不是现有PPO的重新命名。联合考虑传感与移动可参考AIPPMS；本题的计时、硬保证和定向条件仍须自行实现。[R2]

### 统一动作与候选生成

```text
a = (下一停车点q，待测频道序列M，待清频道序列C)
```

候选点来自四类：已发现源的局部几何候选/可清除区域；现有路线附近的多源共用测点；未完成发现证书的边界区域；仍然有效的S3/S25/S21保底点。每次生成有限集合，不直接让网络输出无限连续坐标。

动作成本按实际移动和频道顺序计算。任何位置都可以贡献新观测，但只在确有新增发现、定位或完成证书价值时批量测量，不能每次停车机械扫20个频道。若进入正在执行的双侧定位宏动作，应保留其内部状态，不能重启已做过的轮次。

### 先实现三种有区别的基策略

源优先：优先访问已发现源，途中选择补测与未知频道扫描；证书优先：优先补足未覆盖边界与少数剩余频道；当前G25OR：保留为稳健完成尾策略。滚动评价比较行动后接上这些策略的完成成本，而非只把“当前距离−角度奖励”重新调权重。

### 哪些便宜操作可以作为候选

在已停车位置对接近清除范围的源试清一次；在本就经过的路线位置追加有价值测向；对同一停车点选择一批相关频道。试清失败不误标已清除，单源有次数额度，失败后仍保留完整可能区域与完成流程。

### 中间指标必须记录

记录取消的固定站数、任意停点新增未知频道测量数、双侧定位的启动/中断次数、多源共同观测次数、投机清除的实际绕行与成功率。动作分布不变，不能把“新架构无收益”当作真正实验结论。

## 10  动态证书：Q3与Q4不能使用同一负观测逻辑

### Q3：圆盘并集排除

```text
U꜀ = D ∖ ⋃p∈N꜀ B(p,1000)
```

N꜀是该未知频道实际得到no_signal的所有位置。U꜀为空才证明该频道不存在。工程实现采用覆盖整个目标圆的闭单元；若有负测点到一个单元全部角点的最大距离小于1000，则可以删除此单元，否则细分或保留。不能只删格子中心。

### Q4：位置与方向的互补证据

单个no_signal不能删除1000米圆盘。可先实现局部凸包证书：一个完整单元B位于若干负观测点的凸包内部，且这些点到整个B都不超过1000米，才排除B。更细的方向模型可用连续角区间，而非仅用12个方向代表值。

```text
||p−c||+r ≤ 1000；minφ∈I n(φ)·(p−c) − r ≥ δ > 0
```

若空间单元包含在B(c,r)，上述两个条件保证位置—方向区间中的每个假设都应接收；实际无信号才可删除整块假设。角区间最小值须检查端点与区间内极值，不是只验中心角。颗粒/粒子模型可以排序动作，空粒子集不能直接宣布无源。

### 两个会影响提速上限的事实

第一，Q4外围证据不能随意省掉。一个位于目标圆边界、向外发射的源，对其他圆内测点都可能不可见。因此“只沿真实源TSP行走”不能普遍代替未知频道的外圈排查，除非源数上限等信息已给出独立完成证书。

第二，证明价值有互补性：前两个负测点可能不排除任何二维区域，第三个点才形成凸包。因此仅按“本步新认证面积/本步成本”贪心，可能拒绝有用的前两步。必须考虑两三站组合或完整续行成本，不能擅自套用次模贪心的保证。

## 11  情景Rollout与近邻域路线：怎么实现才不虚高

### 统一以秒为单位比较未来成本

```text
J(a) = averageₖ [ cost(a; ξₖ) + Tbase(b′ₖ) ]
```

从与当前观测一致的候选场景ξₖ出发，为各根动作共用同一组随机情景，执行动作后，以只读观测的基策略估算到全清的剩余耗时。按需加入尾部耗时惩罚，但同时保留只最小化均值的对照；尾部权重是设计选择，不是题目官方评分。

场景模型必须保留同地点固定误差及观测一致性。模拟器可持有样本真值，策略不可直接用真值排序未来目标，否则会把clairvoyant规划伪装成在线算法。不同候选不能各抽一批不匹配案例后直接比较。

### 初始计算预算（待测参数）

可从12个根动作、16个共享情景、两级观测反馈及基策略续行开始；设置每次规划约0.1—0.25秒的可中断预算，超时执行已验证合法的基动作。缓存几何与尾路线，再根据端到端实际运行时间调预算。这些是起始配置，不是已经达到的性能数字。

借鉴DESPOT的有限情景与防过拟合思想，不声称实现了完整DESPOT或继承其理论界。确定性rollout的改进性质也不能直接推广到本题的近似信念模型。[R3,R4] 若进一步做连续观测树搜索，参考POMCPOW处理带权粒子；不要把连续bearing直接塞入朴素POMCP后假定有效。[R6]

### 末段清除路线优化

```text
Cᵢ = ⋂z∈Pᵢ B(z,20)
```

对已获可靠清除证书的源，访问Cᵢ即可，无需到估计中心。先用开放TSP确定访问顺序；固定顺序后，以凸约束||qᵢ−v||≤20（v为Pᵢ顶点）及二阶锥目标最小化相邻距离，再进行2-opt/VNS顺序调整。[R5] 求解器输出必须重新逐顶点验算，可行性不过就回退MEC中心。

### 别把100次零失败当作概率100%的证明

在独立同分布伯努利模型下，100局零失败的95%单侧失败率上界约2.95%；1000局约0.30%。因此统计验证不替代覆盖证明，数学证明也不替代协议/数值/网络回归。版本比较同时给改善区间，p不显著不等于证明等效。
