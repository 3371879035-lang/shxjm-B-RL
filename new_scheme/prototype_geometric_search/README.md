这是2026-09-11依据用户上传的题面和完整接口说明制作的**研究原型**。没有连接或运行官方模拟器，没有改动两个GitHub仓库，不是可直接提交的正式机器人程序。

- 25点构造：36个三角形严格铺满外正十二边形；最大三角形边长975.897m；外多边形内切圆半径1815.941m，覆盖1800m目标圆。20万随机位置/方向未漏检。

## 25点覆盖构造

原点1点；内环12点，半径970m，角度15+30k度；外环12点，半径1880m，角度30k度。k=0,...,11。

将内环多边形三角剖分为12个中心三角形；内外环之间再分成24个三角形。全部边长不超过975.897m。任意目标属于一个三角形；其三个顶点到目标都在1000m内。任意通过目标的闭半平面至少包含其中一个顶点，因此任意180度发射方向都至少能在一个测点被接收。源若恰在内部网格顶点，用相邻三角形形成的邻域论证，不依赖零向量的方位定义。

一条明确的开路路线为：原点→I0→I1→...→I11→O0→O1→...→O11，长18173.851m。原31点、边长950m的三角网格中，任意完整访问路线至少长30×950=28500m。因此完整固定覆盖巡航的路线成本可降低至少36.2%。这不是整局时间提升保证，也不声称25点最少。

## 双侧区间定位：证明要点

以首次有效示向点为原点，读数方向为x轴。取eps=1.01度（传感误差1度加两位小数舍入的保守余量），k=tan(eps)。真实源满足0<=x<=1500、|y|<=kx。

维护x区间[l,u]，宽度>24m时取a=(l+u)/2、b=ak+5，依次检测(a,b)、(a,-b)，先测距离当前位置较近者。

当真实x>=a时，线段[(0,0),(x,y)]与x=a交于(a,ay/x)，此点位于两个探测点之间，且属于首次已接收点与源之间的可见线段。另一方面，两个探测点都比首次测点更靠近源，因为

    distance(q±,g)^2 - distance(0,g)^2
    <= a^2+b^2-2ax+2b|y|
    <= -a^2+b^2+2abk < 0.

最后一个不等式对a>12、b=ak+5成立（算法仅在区间宽度>24时探测，所以a>12）。因此若两点都no_signal，不能是半径不足，且两个点不可能同时位于不可见侧；只能有x<a。单点no_signal不作这种解释。

若有direction，考虑eps误差后可靠判断在a前/后，或定位在a附近很窄的纵向区间。始终继续做误差扇区交会。near直接清除。

每轮区间至少折半，或直接进入足够窄的区间。6轮后宽度<=1500/64=23.4375m。末端在((l+u)/2, ±uk/2)两点清除，矩形内任意目标到至少一个点不超过sqrt(12^2+(1500k/2)^2)=17.856m<20m。最多12次追加检测、2次末端光学尝试。此前已有信息时通常更少。

保守路程上界（从首次正测点直接启动）：沿x方向总变差不超过1500m；全部探测/清除位置的y在[-31.5,31.5]内，至多14次位置变化。因此总路程<=2382m，额外虚拟时间<=2382/5+12×5+2×5=546.4s。该上界不包含重新返回该源附近的跨目标移动和首次测量/首次换频。

这是一种保底成本界，不是该局部问题的最优时间定理。它只适用于本题静止、持续辐射、固定半径、180度定向覆盖和有界测向误差模型。

## 验证分布

`uniform`：10–16源随机，位置圆内面积均匀，半径1000–1500m，第4问各源独立以0.5概率设为定向，方向均匀。这不是官方分布。

`edge`：源距圆心1650–1800m、接收半径1000m；第4问全为径向朝外定向源。这是额外压力测试（全定向是题面混合情形的极端扩展），不代表官方常态。

同组各策略逐一复用相同场景种子、源数据和固定空间误差场。所有测量停止后进行，clear不改频道。成功率由最终真值清除数复核，不只依赖内部done标志。

G31：Q3用7点/Q4用31点 + 新双侧局部定位 + 开路最近邻/2-opt。
G25：Q4仅将31点换成25点。
G25O：再加入已有行程停点的机会式补测。Q3仍是7点，名称G25O只为脚本统一标识。

每局额外测量成本、失败清除成本、移动成本均完整计入虚拟时间。失败局不能在报告中静默删除。
