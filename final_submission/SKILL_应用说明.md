# 论文写作使用的 skill 说明

本论文按数学建模竞赛相关 skill 工作流完成。以下说明各 skill 的应用位置与最终产出。

| Skill | 应用位置 | 具体工作 |
| --- | --- | --- |
| competition-workflow | 全流程 | 明确任务、形式化表示、代码实现、验证、结果解释和论文输出 |
| problem-classification | 第一、二章 | 判定本题为部分可观测、硬几何约束与在线决策的混合问题 |
| question-routing | 第一、二章 | 为问题1-4分别路由到几何求交、第二测点、覆盖搜索和双侧定位清除 |
| model-selection | 第二、十一章 | 比较端到端RL、纯规则、几何保证+调度三类路线，最终选用几何保证主动搜索+A0调度 |
| baseline-design | 第十、十一章 | 设计传统方法、旧安全PPO、G25O、G25OR和G25O-R full五类基线 |
| model-comparison | 第十章 | 本地严格配对、官方随机案例分布比较、统一T指标和统计检验 |
| model-formulation | 第四、五、六章 | 半平面、可行域、覆盖证书、双侧区间和奖励函数等数学定义 |
| algorithm-writing | 第四、八、九章 | 算法1定位区域、算法2在线流程，明确输入输出、步骤与复杂度 |
| paper-structure | 全文 | 问题重述、问题分析、假设与符号、模型、算法、实验、结论、参考文献、附录 |
| abstract-writing | 摘要 | 按问题-方法-结果-结论组织，摘要连同标题和关键词控制在一页内 |
| academic-polish | 全文 | 统一术语、单位、公式符号和客观表述，删除无依据的强化学习增益表述 |
| result-table | 第十章 | 所有结果表均为三线表，带单位、样本量、对比对象和显著性信息 |
| scientific-plot | 论文插图 | 8幅图均为300 dpi，标注坐标轴名称、单位和图例；图内不重复图题 |
| conclusion-writing | 第十二章 | 逐问回答问题，区分已完成演练与尚未执行的正式测试 |
| consistency-checker | 全文 | 论文数值与数据记录、代码输出交叉检查 |
| reproducibility-checker | 附录A | 给出运行顺序、数据路径、核心源码和支撑材料清单 |
| reviewer-agent | 全文审查 | 检查正确性、完整性、创新性、可复现性和表达规范 |
