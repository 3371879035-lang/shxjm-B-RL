# B题：无线电干扰源快速自动定位与清除（几何保证主动搜索）

本目录给出 2026 高教社杯 B 题的完整实现：数学建模、几何保证模块、覆盖发现证明、有限步骤光学保底、本地随机环境、带动作屏蔽的 PPO，以及官方模拟器 HTTP+JSON 适配器。

最终主方案为 G25OR 几何保证主动搜索。覆盖证书、频道账本、双侧区间定位、MEC 清除证书和有限步骤光学保底构成正确性保证；执行策略使用确定性 A0 调度。仓库同时实现带动作屏蔽 PPO 作为可选调度消融，但本地和官方实验中 PPO 均未偏离 A0，未独立产生速度收益。原方案B的RL字样保留在历史提交和消融代码中。

strategy 可选：
- heuristic：仅用 A0 确定性保底策略；
- ppo：直接用 PPO 动作（动作屏蔽和A0先验仍在）；
- hybrid：默认安全门，PPO 偏离 A0 先验且概率优势不足时采用 A0 动作。

## 4. 数学保证

- 问题1：示向误差锥的3个半平面与目标圆域外切多边形求交；枚举顶点对得直径；最小包围圆判断一次清除是否可保证。
- 问题2：全向源的可靠第二测点候选区域 Q_vis = { q : max_{z in F} ||q-z|| <= 1000 }；可直接使用的起点 q± = s1 + 750u ± 300v，最坏接收距离约 817.65m。
- 问题3：7点覆盖（原点 + 半径1200正六边形），最坏发现距离约 968.90m。
- 问题4：边长 950m 的等边三角网格共31点，对任意180°定向源至少一点可见。
- 单源保底：一次有效示向后，2×61 个清除点覆盖长度1500m、半宽<26.18m的矩形，最远约18.11m<20m。
## 5. 完成条件

程序只有在以下证书成立时才调用 /exit：

1. 已成功清除至少 16 个不同频道（由题面上限推出任务完成）；或

RL 网络不能自行提前退出；所有动作屏蔽与有限额度（每源最多 6 次额外局部测量）都在网络之外实现。

## G21A零绕行补测矩阵实验（负结果）

按S21保证覆盖+路段中间补测点+预测MEC收缩选择+Q4每源1次+失败不删可行域+双侧保底实现G21A。六类场景、N=10..16、每类每组15组矩阵共630对、1260次运行：

- 全部630对清除；
- G21A总体平均V/源544.13 s，G25OR-S21为524.84 s，G21A慢3.68%（p≈3.7e-77）；
- 均匀+5.18%、边缘+5.52%、聚集+2.99%、最小半径+4.13%、朝外+0.29%、混合+5.07%；
- 补测后直接获得清除证书平均仅0.04-0.06次。

诊断：方向型第二观测主要压缩横向不确定度，没有压缩双侧定位所依赖的首测距离区间；6 s补测成本大于节省的定位移动。G21A未达淘汰门槛。官方问题4各100局验证：G21A 100/100清除、聚合540.00 s/源；S21基线100/100清除、514.15 s/源；G21A慢5.54%（Mann-Whitney p=0.046），确认没有净收益。停止G21A/G21X/S21扩展，最终方案仍为G25OR-S25。数据见`results/extreme_plan/g21a_matrix_*`。
